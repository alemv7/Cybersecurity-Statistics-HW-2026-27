HW 05 · Riemann vs Lebesgue and the normal CDF

Alessandro Bertoldi · Statistics in Cybersecurity. Exercise 1: numerical integration by partitioning the domain (Riemann) or the range (Lebesgue). Exercise 2: computing Φ(x) numerically.

Exercise 1

01Two ways to cut the area

  • Riemann-inspired. Partition the domain [a,b] into N subintervals of width h and add f(tag)·h. Variants: left endpoint, midpoint, trapezoid.
  • Lebesgue-inspired. Partition the range into K levels of height δ = Y/K (Y = sup f) and add up level × measure of the preimage. For f ≥ 0 this is the layer-cake sum
L_K = Σ_{j=1..K} δ · μ({x : f(x) ≥ jδ}) = ∫ δ·floor(f/δ) dμ ≤ ∫ f dμ, error ≤ δ·(b−a)
  • Exact preimage: μ({f ≥ y}) from a formula (or a root-finding step for sin x / x). Sampled preimage: for a generic f, evaluate f on N sample points, sort the values, and estimate μ({f ≥ y}) by the fraction of values ≥ y, which is cheap (O(N log N)) but is in fact a Riemann sum in disguise.
  • For 1/√x the range is unbounded, so the levels are truncated at Y = √K, which balances the two error terms (δ = Y/K and the tail 1/Y).

03Pathological functions

Dirichlet (1 on rationals, 0 on irrationals): every subinterval contains both kinds of points, so the upper Darboux sum is 1 and the lower one is 0 for any partition: not Riemann integrable. The rationals are countable, hence have measure 0, so every preimage {f ≥ y} (0 < y ≤ 1) has measure 0 and the Lebesgue integral is 0. Thomae (1/q at p/q in lowest terms, 0 at irrationals): continuous at every irrational, discontinuous only on the rationals (measure 0), so it is Riemann integrable (Lebesgue's criterion) and both integrals are 0.

Floating-point numbers are all rational, so a program cannot test rationality; the tags are therefore modeled exactly: a rational tag k/N, or an irrational tag (k + √2/2)/N.

04Discussion

  • Same value? For Riemann-integrable functions (bounded and continuous almost everywhere) the Lebesgue integral exists and equals the Riemann integral, and both numerical schemes converge to it: the tables show the same limit for sin x, x², |x−½|, the step functions and sin x / x. Differences are in how they converge, not where.
  • Different behaviors. 1/√x is unbounded: Riemann sums need an improper-integral limit (left and trapezoid sums fail at x = 0, the midpoint converges slowly, as 1/√N), while the Lebesgue integral exists directly and is 2. The Dirichlet function has no Riemann integral at all but a Lebesgue integral equal to 0. For Thomae both exist and are 0, though a Riemann sum with rational tags is positive for finite N and only tends to 0.
  • Accuracy and convergence. Smooth functions: midpoint and trapezoid errors scale like 1/N² and the left sum like 1/N. A jump costs a Riemann sum O(1/N) (one wrong cell). Lebesgue error is O(δ) = O(1/K) for any bounded f, smooth or not, because it depends on the range partition only; the sampled version also carries the sampling error of the preimage measure.
  • Efficiency. Riemann: N function evaluations and no extra knowledge. Lebesgue with exact preimages: K cheap evaluations of μ but requires solving f(x) = y analytically or by root finding (about 50 function calls per level for sin x / x). Without that, the sampled version costs O(N log N) for the sort. Lebesgue's advantage is conceptual and theoretical: it handles wild functions and limits (monotone and dominated convergence), not speed.
Exercise 2

05Why Φ is not elementary

Φ(x) = ∫_{−∞}^{x} φ(t) dt, φ(t) = e^{−t²/2}/√(2π)

Liouville's theorem (1835; Rosenlicht's form): let f and g be rational functions. Then ∫ f(x)·e^{g(x)} dx is an elementary function if and only if there exists a rational function R with

R′(x) + g′(x)·R(x) = f(x), and then ∫ f e^g dx = R(x)·e^{g(x)}

Application. Here f = 1 and g = −x²/2, so we would need a rational R with R′ − xR = 1. (i) If R had a pole at a of order k ≥ 1, R′ would have a pole of order k+1 there, while xR has order k, so R′ − xR could not equal 1. (ii) So R is a polynomial of degree d; then R′ − xR has degree d+1 ≥ 1 (leading term −c·x^{d+1}) but must equal the constant 1: contradiction (if R = 0 the left side is 0, not 1). Hence ∫ e^{−x²/2} dx is not elementary: no finite combination of polynomials, exp, log, roots and trigonometric functions gives Φ.

A note on wording. "The integrand has no antiderivative" is imprecise: antiderivatives exist (Φ itself is one), they are just not elementary. The course notes (Hogg–McKean–Craig §3.4) give one as a power series, obtained by integrating the series of e^{−x²/2} term by term (allowed by its absolute convergence):

Φ(x) = ½ + (1/√(2π)) · Σ_{k≥0} (−1)^k · x^{2k+1} / (2^k · (2k+1) · k!)

It is an alternating series, so the Alternating Series Estimation Theorem bounds the truncation error by the first omitted term (checked numerically below), and symmetry Φ(−z) = 1 − Φ(z) gives negative arguments. The normalizing constant comes from (∫e^{−x²}dx)² = ∫∫e^{−(x²+y²)}dx dy = π in polar coordinates. Reference for Liouville's result: M. Rosenlicht, Integration in Finite Terms, Amer. Math. Monthly 79 (1972).

Special function. The error function is defined by erf(z) = (2/√π)·∫₀^z e^{−t²} dt (DLMF §7.2), and it is essentially the standard normal CDF up to scaling and translation, which gives the exact analytic representation

Φ(x) = ½ · [ 1 + erf( x/√2 ) ] = ½ · erfc( −x/√2 )

This is an exact identity, but erf is only defined by an integral (or an infinite series): the name does not tell us how to get a number. Processors have no erf instruction, so every implementation still needs a numerical method: integration, a power series, a continued fraction, or a fitted approximation. The problem is moved, not removed.

06Numerical methods compared with a trusted reference

  • Trapezoid / Simpson on ∫₀^x φ, then Φ = ½ + integral (N panels).
  • erf power series: erf(z) = (2/√π) Σ (−1)ⁿ z^{2n+1}/(n!(2n+1)), Φ = ½(1 + erf(x/√2)). The terms alternate and grow like e^{z²} before shrinking: cancellation for large |x|.
  • Kummer series: Φ(x) = ½ + φ(x)·Σ x^{2n+1}/(1·3·5⋯(2n+1)): same function, all terms of the same sign, so no cancellation.
  • Polynomial approximation Abramowitz–Stegun 26.2.17 (|error| < 7.5·10⁻⁸): one exponential and a degree-5 polynomial.
  • Hybrid: Kummer series for |x| < 2 and the continued fraction for the Mills ratio Q(x) = φ(x)/(x + 1/(x + 2/(x + 3/(x + …)))) for the tails, which keeps full relative accuracy there.

07Z-scores and the 68–95–99.7 rule

For X ~ N(μ, σ²) the course notes use z = (x − μ)/σ, so that P(X ≤ x) = Φ(z), and the symmetry Φ(−z) = 1 − Φ(z). The probability within k standard deviations is P(μ − kσ < X < μ + kσ) = 2Φ(k) − 1.

08Conclusions

  • No elementary antiderivative exists for e^{−x²/2} (Liouville), but erf gives an exact definition; it still has to be computed numerically.
  • Trapezoid converges like 1/N² and Simpson like 1/N⁴ until the rounding floor (~10⁻¹⁶); series converge geometrically after about x² terms; the polynomial approximation is the fastest but stops at about 10⁻⁷.
  • Absolute error is not enough: in the tails Φ(−8) ≈ 6·10⁻¹⁶, so a method with absolute error 10⁻¹⁶ has 100% relative error. Methods that compute 1 − Φ or ½ − ∫ lose all digits there, while the continued fraction keeps full relative accuracy. Choose the method according to the range of x and to the accuracy that the application needs.
